# Windcode 重构验收标准矩阵

Source: ignored historical `spec/*/spec.md` and `spec/*/checklist.md`; evidence is restricted
to currently Git-tracked tests. This file records the Phase 0 characterization baseline. `AUTO` means a
specific pytest node or tracked test path exists, `SMOKE` is a reproducible command, `MANUAL` is
an intentional visual/operational check, `GAP` means the cited evidence is only partial, and
`GAP-CONFLICT` means current tracked behavior contradicts the historical AC.
